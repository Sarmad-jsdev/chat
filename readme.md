One final tip

Your English does not need to be perfect. Speak slowly and clearly. If you forget a word, don't stop—use simple sentences like:

"This page is used for..."
"Here the user can..."
"After clicking this button..."
"The backend sends the data to MongoDB."
"This feature improves accessibility."

A clear explanation in simple English is much better than trying to memorize difficult sentences.
