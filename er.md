User Registration & Login

Users (Admin, Form Creator, Respondent) register and log in using accessible forms.

Full keyboard navigation and screen reader support during authentication.

Admin Management

Admin manages user accounts and roles.

Admin monitors surveys and ensures WCAG 2.1 accessibility compliance.

Admin reviews accessibility reports and system usage analytics.

Accessible Survey Creation

Form creators build surveys using a drag-and-drop interface.

Creators select question types (MCQs, text, ratings, file uploads).

Accessibility options such as alt text, labels, ARIA roles, and contrast themes are configured.

Survey Customization for Accessibility

Creators enable high-contrast, dyslexia-friendly, and large-text modes.

Video questions include captions or sign-language support.

Keyboard-only and screen reader–optimized layouts are applied automatically.

Survey Distribution

Surveys are shared via web links, QR codes, or SMS.

Accessible invitations are generated for different participation methods.

Survey Participation (Respondent)

Respondents complete surveys using keyboard, screen readers, or touch devices.

Voice-based responses are supported via speech-to-text.

SMS-based survey completion is available for low-connectivity users.

Adaptive Response Handling

System adapts input/output methods based on user needs (voice, text, SMS).

Live ARIA announcements guide users through form progress.

Response Submission & Validation

Accessible error handling with clear messages.

Users receive confirmation feedback via visual, audio, or text alerts.

Analytics & Reporting

Form creators view responses in an accessible dashboard.

Graphs and tables are screen reader–friendly.

Data can be exported in CSV, Excel, or PDF formats.

Accessibility Testing & Evaluation

Built-in accessibility checks using tools like axe-core.

WCAG compliance validation before publishing surveys.

Version Control & Deployment

Source code managed via GitHub with documentation.

Application deployed with accessibility tested across devices and browsers.
